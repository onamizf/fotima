# Минималистичная главная — выпуск 1.3.0

Маршрут: `#home`. Изменена композиция главной; welcome, шапка, боковое меню, лабораторные, условия доступа, сохранения, XP и поиск продолжают работать по прежним правилам.

## Как выглядит экран

1. Белый hero с лёгким голубым свечением: приветствие по времени Ташкента, заголовок в обычном регистре с синим именем, поиск и четыре компактных фильтра. Справа — основной персонаж высотой 260 px с небольшим выходом за край. На планшете он 200 px, на телефоне скрыт.
2. «Темы курса»: горизонтальная лента стеклянных карточек 200×132 px. В них — линейный значок, номер/замок, название до двух строк, полоса настоящего прогресса. Полное название остаётся в доступном тексте; для открытых тем также есть подсказка. Для пустого фильтра используется существующий перевод пустого состояния.
3. Четыре инструмента: таблица Менделеева, словарь, тесты, игры. Круглая стрелка и «Ещё» с главной убраны. Отдельная страница библиотеки сохраняет прежние ссылки.
4. «Твоя лаборатория»: семь карточек в одной сетке.

```text
ПК
┌───────────────────────┬────────────┬────────────┐
│                       │ Следующий  │ Статистика │
│      Продолжить       │   опыт     │            │
│                       ├────────────┼────────────┤
│                       │ Следующая  │ Опыт дня   │
│                       │   тема     │            │
├───────────────────────┴────────────┼────────────┤
│               Факт дня             │   Вызов    │
└────────────────────────────────────┴────────────┘
```

На планшете две колонки, карточка продолжения занимает всю ширину. На телефоне — один столбец. При раскрытой боковой панели сетка учитывает доступную ширину, чтобы не сжимать текст. Базовая высота ряда 168 px; ряд может немного вырасти для перевода, чтобы сохранить кнопки и весь текст внутри карточки.

Убраны верхний баннер, прежняя плашка серии/XP и кнопка достижений в hero. Эти данные находятся в карточках продолжения и статистики. Плавающий помощник скрыт только на главной; на остальных страницах остаётся. Маленький аватар у факта — часть карточки, а не второй плавающий персонаж.

## Дизайн и данные

Цвета, отступы, радиусы и тени вынесены в `:root` нового CSS. Большие поверхности — белые/стеклянные/тёмно-синие, у факта мягкий кремовый фон. Яркие круги заменены линейными значками Lucide. Заголовки секций и карточек больше не набраны капсом; uppercase сохранён у overline. На главной три единых вида действий: тёмная основная кнопка, белая с обводкой, текстовая ссылка. В карточке не больше одной основной кнопки.

`CourseGame.dashboardSnapshot()` — только чтение существующих данных: тот же опыт дня, тот же факт дня, серия, XP, звание, порог следующего звания и результат сохранённого вызова. Он не начисляет очки, не меняет схемы хранения и не завершает задания. Основные кнопки используют прежние `data-open-experiment`, `data-topic-tab` и hash-маршруты.

В текущем хранении есть только одна сохранённая попытка быстрого вызова, без истории рекордов. Поэтому карточка честно показывает **«Результат: 2/3»** (либо «—»), а не объявляет последний результат историческим рекордом. Новое хранение рекордов не добавлено, поскольку задача ограничена представлением.

Приветствие обновляется при отображении и раз в минуту, без записи прогресса. Все новые подписи есть в RU/UZ/EN; кириллический узбекский использует существующий переводчик. Локальные превью лабораторий и веществ переиспользованы; маленькая картинка у опыта дня декоративная. Никаких удалённых изображений или CDN.
