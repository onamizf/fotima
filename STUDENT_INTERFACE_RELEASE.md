# Главная и шапка — выпуск 1.2.0

Маршрут: `#home`. Welcome, фон #1F6BFF, существующие шрифты, боковая навигация, задания и правила начисления XP сохранены.

## Главная

Поиск открывается от двух символов. Результаты сгруппированы: темы, опыты, 118 элементов и словарь; сначала не более четырёх строк в группе. «Показать все (N)» раскрывает остальные результаты этой группы внутри списка. Совпадения в названиях выделены жирным. У каждой строки есть цветной значок и подпись типа; у закрытых тем/опытов — замок и условие открытия. Темы «Скоро» не обещают открытие после уже готовой темы.

Список имеет высоту до 420 px, тень и свой скроллбар. У hero и ряда разделов устранены контексты наложения, создававшиеся анимацией/изоляцией; результаты находятся над иконками. Фон затемняется. Esc и клик снаружи закрывают список, стрелки выбирают строку, Enter открывает доступный результат. Элементы ведут в реальные карточки `#resources/periodic/{symbol}`. Пустой поиск показывает помощника.

В баннере отображается текущая тема и число оставшихся шагов из реального прогресса. После завершения предыдущей темы показывается новая доступная тема; после всех готовых тем — сообщение о завершении. Закрытие баннера сохраняется отдельно для ученика и состояния темы.

Все ярлыки разделов получили одинаковую ширину 110 px и подпись до двух строк. Стрелка прокручивает горизонтальный ряд, включая планшеты.

В «Продолжить обучение» теперь две цельные карточки одинаковой высоты на ПК: локальное превью высотой 200 px, название, кольцо процентов, три состояния «Теория / Опыты / Тест» и продолжение; справа — следующий опыт, значок, примерное время и кнопка. На телефоне карточки идут друг под другом. У изображения и содержимого нет пустой промежуточной области; кнопки остаются внутри карточек.

## Шапка

Справа: приветствие, существующая шкала звания/XP, **колокольчик → язык → профиль**. Три кнопки имеют размер 44×44 px и промежутки 12 px. На телефоне приветствие и XP-полоска скрыты, остаётся компактный значок звания; полное звание/XP по-прежнему доступны в подписи ссылки на прогресс.

У языка — свой белый список с полными названиями четырёх языков, выбранным пунктом и галочкой. Переключение применяется сразу и сохраняется; появляется короткий тост. Поддерживаются стрелки, Enter, Space и Esc. Невидимый нативный `#language` оставлен как адаптер для существующей логики/проверок; пользователь видит только новое меню.

Контроллер разрешает открыть только одну панель языка, уведомлений или профиля. Клик снаружи и Esc закрывают её; Esc возвращает фокус на кнопку. На телефоне все три панели становятся нижними шторками с ручкой, затемнением и блокировкой прокрутки фона. Внутри шторки удерживается клавиатурный фокус. При уменьшенном движении анимации отключены.

## Уведомления

Новый журнал `notifications` версии 1 находится в существующем персональном состоянии `fotima.chemistry7.curriculum.v2.local-user.{id}`. Записи имеют поля `{id,type,title,text,link,createdAt,read}`; заголовок и текст хранятся в переводах, поэтому старые записи тоже меняют язык. Максимум — 50 записей, сначала новые. Список `seen` не позволяет повторно создать удалённое или отключённое событие.

Автоматические события:

- доступ к готовой теме;
- новый значок;
- новое звание (без изменения начисленных XP);
- серия от двух дней, одно событие в день;
- стартовое системное сообщение о местном сохранении.

При первом подключении старого аккаунта журнал не заваливает ученика ретроспективными значками и званиями: создаётся текущая доступная тема и системная запись. При отключённом типе будущие события этого типа не добавляются, включение не возвращает пропущенные события.

В панели: число непрочитанных до «9+», все/непрочитанные, прочитать все, переход по записи, удаление кнопкой или свайпом. После свайпа подавляется случайный переход по ссылке. Группы «Сегодня / Вчера / Ранее» вычисляются в **Asia/Tashkent**. Пустое состояние — помощник. Подвал ведёт на прогресс и настройки.

В настройках есть пять переключателей типов и отдельный звук уведомлений. Он выключен по умолчанию, независим от звуков игры, использует короткий локально синтезированный сигнал после взаимодействия пользователя. Новые записи могут покачивать колокольчик; уменьшенное движение отключает этот эффект. Изменения/чтение/удаление сохраняются без начисления XP.

## Проверки

```sh
node tests/validate_notifications.cjs
LAB_TEST_BASE=http://127.0.0.1:8044/ python tests/student_interface_e2e.py
LAB_TEST_BASE=http://127.0.0.1:8044/ python tests/notifications_touch_e2e.py
python tests/site_package.py
python tests/release_cache_e2e.py
```

Для проверки событий от завершения темы используется `/tmp/intro-complete-state.json`, получаемый настоящим проходом `tests/intro_e2e.py`. Проверка `notifications_touch_e2e.py` требует этот файл. Основной сценарий главной проверяет доступную фикстуру при её наличии и отражает это в отчёте.

Проверяются четыре языка, ширины 320/375/390/768/1024/1440, геометрия панелей и карточек, наложение через hit testing, обычное хранение и отдельные аккаунты, реальные маршруты. Chromium с touch-эмуляцией не заменяет испытание физических устройств. Завершение GitHub Pages deployment нужно проверять отдельно от локальной проверки веб-пакета.
