# Установки: версия 1.41.1

## Что изменено

- `src/water-bath-atlas.js`: один JSON-атлас для водяной бани и выпаривания, разборка/сборка, ползунок, отдельный фокус, адаптивная сетка и калибровка.
- `src/water-bath-page.js`: шаги и карточки двух заданий. Сборка открывается после посещения всех карточек частей; вещества не входят в этот счётчик.
- `src/apparatus-assembly.js`, `src/apparatus-labels.js`: адаптер сборки задания 3 через общий вход `AssemblyWorkshop.mount`, подписи a–d, клавиатура, перенос чипов и касания.
- `src/water-bath-workshop-skin.js`: восемь новых изображений поверх прежних проекций 3D-объектов. Геометрия, привязки, порядок действий, хитбоксы и проверки задания 2 сохранены.
- `data/{water-bath,evaporation}.json`, `data/water-bath-i18n.js`, `data/apparatus-progress.js`: данные, переводимые строки, сохранение и проверка прогресса.
- `assets/backgrounds/`, `assets/equipment/{water-bath,evaporation}/`: оригинальные файлы последнего архива; WebP и PNG/JPG для запасного варианта. Общие приборы не дублируются.
- `src/lab-backgrounds.js`, `src/water-bath.css`: фоны и оформление. Фон темы 1.2 применяется к заданиям 1–3; в единственном существующем задании 1.1 новый фон обрамляет исходные учебные сцены, сохраняя содержание опасных ситуаций. В работе 1.1 заданий 2 и 3 нет; новые задания там не создавались.
- `src/{project-workspace,project-hub,safety-workspace,equipment-collection,assembly-workshop,setup-workshop-scene}.js`, `data/{course.js,topics/ch1/practical-1-2.js}`, `index.html`, `version.json`, `tools/build_site.py`: подключение, маршрут задания 3, сохранение старых результатов и упаковка JSON. README и preview архива не публикуются.

## Координаты

- Водяная баня: `?v=1.41.1&debug=1#lab/ch1/1.2/task-2`.
- Выпаривание: `?v=1.41.1&debug=1#lab/ch1/1.2/task-3`.

Выберите часть в списке, перетащите её рамку или измените x/y/w/h/z. «Скопировать координаты» выдаёт весь JSON. Сохраните изменённые `parts[].assembled` в соответствующем файле `data/`. Калибровка атласа не изменяет механику старой сборки задания 2.

## Прогресс и XP

Сохранённая сборка задания 2, её награды, изученные приборы и коллекция задания 1 сохраняются. Ранее изученные приборы переносятся в новый счётчик; новые отдельные карточки муфты и лапки нужно открыть. Существующие награды не дублируются. Для задания 3 новый тариф XP не задан — результат сохраняется без XP (TODO отмечен в данных).

## Старые изображения в сборке задания 2

Без замены остались склянка с водой, склянка со спиртом, коническая колба, воронка, мерный цилиндр, выпарительная чашка, спиртовка, пробиркодержатель, тигельные щипцы и ступка с пестиком. В наборе `water-bath/parts/` соответствующих изображений нет. Отдельные изображения веществ не подменяют склянки.

## Проверки

- `python tests/validate_apparatus_data.py`: файлы, PNG-фолбэки, пропорции full, переводы, общие пути, координаты и ответы.
- `node tests/validate_apparatus_progress.cjs`: миграция старого изучения, сохранение коллекции и проверка результатов.
- `python tests/water_bath_atlas_e2e.py`: 360×800, 390×844, 768×1024, 1366×768, 1920×1080, 2560×1440; карточки, режимы, старая сборка, нагрев, отмена/повтор, сохранение XP, debug. Сравнивает рамки всех восьми заменённых приборов до и после замены; о расхождении сообщает предупреждением.
- `python tests/evaporation_e2e.py`: все шаги задания 3, неверный порядок, подписи, клавиатура, сохранение и отсутствие нового XP.
- `python tests/apparatus_touch_e2e.py`: настоящие touch-события Chromium для ползунка и касания для прохождения.
- `python tests/apparatus_motion_e2e.py`: переход full/parts, ползунок, подсказка отдельно для каждой установки, reduced motion.
- `tests/workspace_release_e2e.py`, `tests/equipment_collection_motion_e2e.py`, `tests/home_chips_e2e.py`: регрессии задания 1.1, коллекции и главной страницы.

Все изображения задания 3 уже есть в обновлённом архиве и установлены; класть заглушки или новые картинки не нужно. При желании можно уточнить координаты через debug. Не-русские значения новых текстов пока временно повторяют русский и помечены TODO. Safari/WebKit в рабочей среде отсутствует: требуется проверка на настоящем Safari/iPhone.
