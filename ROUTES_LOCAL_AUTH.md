# Маршруты, синяя тема и локальные аккаунты

Изменения от 22 октября 2026. Композиция, размеры, шрифт, персонаж, cursor-tracking и анимации `#welcome` сохранены. В шапке изменены только навигационное поведение контактов и подсветка активного пункта.

## Маршруты

| Hash | Назначение |
|---|---|
| `#welcome` или пустой hash | Входной hero, доступен без аккаунта |
| `#catalog` | Опыты: каталог трёх уровней |
| `#home` | Прежний экран уровней; старые ссылки работают |
| `#register` | Регистрация по имени и паролю |
| `#login` | Вход по имени и паролю |
| `#account` | Профиль вошедшего ученика; для гостя — регистрация |
| `#contacts` | Проект, автор onamizf, заглушки email/Telegram, возврат на главную |
| `#progress`, `#settings` | Прогресс и настройки |
| `#theory/{topic}` | Теория |
| `#lab/{topic}` | Лабораторная |
| `#result/{topic}` | Результат |
| `#table/properties` | Таблица свойств |
| `#materials/properties` | Оборудование |
| `#notfound`, неизвестный маршрут/тема | 404 с кнопкой возврата |

`topic`: `properties`, `physical`, `chemical`. Учебные страницы требуют локального входа и прежних условий открытия уровней. Контакты и 404 общедоступны. Вход и регистрация заканчиваются переходом в `#catalog`. Восстановление сессии при F5 сохраняет текущий hash; браузерная история использует обычный `hashchange`. Якорь пропуска к `#main` прокручивается плавно, кроме reduced motion. Пустых href и ссылок `href="#"` в текущих экранах нет.

Для неизвестного физического пути GitHub Pages предусмотрен `404.html`. Все обычные ресурсы подключены относительными путями; публикационный пакет испытан под `/fotima/`. Автор указан публичным ником владельца репозитория `onamizf`. Email и Telegram пока не предоставлены: показаны текстовые заглушки без выдуманных mailto/Telegram-ссылок. Их можно заполнить в `src/routes.js`.

## Локальная авторизация

`src/auth.js` заменяет прежний Supabase-клиент. Он не отправляет запросы к сервису и не содержит поля email. Имена проверяются после trim/NFC: 3–20 символов, латиница/кириллица, цифры 0–9, `_` и обычный пробел. Сравнение имён без учёта регистра. Пароль от восьми символов Unicode и совпадающий повтор обязательны; видны счётчик, переключатель видимости и ошибки под полями. Невалидная форма не отправляется.

Пароль не сохраняется открытым: Web Crypto вычисляет SHA-256 от `salt + ':' + password`; соль — индивидуальные 32 криптографически случайных байта. Реестр содержит только id, отображаемое/нормализованное имя, соль и хеш. Web Locks защищает регистрацию одинаковых имён из двух вкладок; там, где API недоступен, имя повторно проверяется перед синхронной записью. Сессия хранит id пользователя и случайный id сессии. После входа видны имя и выход; прогресс сохраняется под отдельным ключом пользователя.

Ключи:

- `fotima.local.accounts.v1` — реестр имён, солей и хешей;
- `fotima.local.session.v1` — текущая сессия;
- `fotima.chemistry7.curriculum.v2.local-user.<id>` — прогресс этого пользователя.

Прежние ключи Supabase, гостевой прогресс и настоящая база не удаляются и не связываются автоматически с новым именем. Архив старых сценариев email-входа: `tests/legacy_supabase/`. Пароли и аккаунты не синхронизируются между устройствами. После очистки данных браузера локальные аккаунты недоступны. Это статическая браузерная авторизация по запросу заказчика, а не серверная защита от редактирования собственного localStorage. Web Crypto требует HTTPS или localhost; некриптографического/открытого запасного хранения паролей нет.

## Единая тема

`site.css` определяет `--bg`, `--bg-glow`, `--text`, `--card`, `--card-solid`, `--accent-dark`. Фон всех страниц синий, читаемые карточки и формы белые с тёмно-синим текстом, кнопки — белые таблетки, заголовки — Inter Tight 900 uppercase. Старые CSS-фоны заменены переменными. Интерфейсные модальные окна используют синюю тему; боковая навигация оформлена как читаемая белая панель. Переключение на прежние серую/тёмную темы снято, так как теперь задан единый фон.

Цвета настоящих учебных образцов, стекла, пламени и комнаты внутри WebGL/SVG остаются частью модели опыта: они не перекрашиваются как фон сайта. Проверки и условия получения учебных результатов не менялись.

## Проверки

1. `tests/local_auth_e2e.py`: живые проверки полей, регистр/Unicode, правильный SHA-256, разные соли для одинаковых паролей, отсутствие открытых паролей, сессия/F5, разные пользователи, неизменность прежних ключей, вкладки/одновременные имена, отказ хранилища.
2. `tests/routes_theme_e2e.py`: 21 маршрут, 128 раскладок, 17 уникальных внутренних href, история, F5, мобильные меню, синий фон, отсутствие ошибок JS/ресурсов, сохранение геометрии hero.
3. `tests/progress_e2e.py`: реальная регистрация и полный учебный путь — 12 образцов, сравнение, три физических задания и восемь химических вариантов; 96 раскладок и сохранение/сброс/совместимость старых проверенных данных.
4. `tests/welcome_e2e.py`: 24 раскладки hero, часы, tracking, touch, reduced motion, новые переходы.
5. `tests/blue_webgl_e2e.py`: настоящий WebGL в трёх лабораторных и первые реальные действия, Chromium SwiftShader.
6. `tests/site_package.py`: пакет `/fotima/`, локальный вход, четыре языка, относительные ресурсы и физическая страница 404.
7. `node tests/validate_lessons.cjs`: четыре языка, 12 уроков, 36 разделов, 24 вопроса и 72 пояснения.

Новая публикация GitHub Pages отдельно этими локальными проверками не подтверждается. Проверки браузерные, без испытания физического телефона, Safari или Firefox.
