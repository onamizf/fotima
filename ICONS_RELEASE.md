# Иконки — выпуск 1.5.0

Добавлены все 28 оригинальных PNG из пользовательского `icons.zip`. Каждый файл 134×134, RGBA; изображения скопированы без изменения. Новые PNG не генерировались.

`Icon(name, size)` в `src/icons.js` — единая точка вывода. Декоративные изображения имеют пустой alt, aria-hidden, lazy loading, запрет перетаскивания и относительные URL `assets/icons/…`. Служебные значки без PNG проходят через тот же API и локальную выборку Lucide (20px, stroke #1E2A4A/2). Иллюстрации приборов, знаки опасности, схемы молекул и изображения веществ сохраняют учебное назначение.

Иконки тем берутся из `topic.icon` во всех представлениях, включая закрытые темы и уведомления. Иконка опыта берётся из `exp.icon` либо из поля icon его темы. В текущих 40 заданиях нет реакции с образованием осадка: соответствующий PNG и поддержка метаданных готовы, но существующие опыты не переименованы и не заменены.

Размеры: меню 32/40px; колокольчик 36px; карточки тем 56px; станции маршрута 72px; заголовки тем 96px; bento 44px; результаты/уведомления 36px; игровые показатели в тексте 20px. Подложки под готовыми плитками удалены. Закрытая тема показывает собственную приглушённую иконку и маленький Lucide-замок. Анимации отключаются при reduced motion.

Маршруты, обработчики действий, вход, XP, учебные условия, сохранения и численность заданий сохранены.

## Изменённые файлы

- `assets/icons/*.png` — 28 предоставленных изображений.
- `src/icons.js`, `src/icons.css` — общий вывод, метаданные иконок, размеры, состояния, наведение и доступность.
- `data/topics.js`, `data/topics/intro.js` — поля icon у семи тем и существующего задания по разделению смеси.
- `src/course.js`, `src/intro-ui.js` — маршрут, тема, задания, вкладка мини-теста, заголовки.
- `src/dashboard.js` — главная, bento, инструменты, поиск, библиотека и тесты.
- `src/profile-menu.js` — меню, прогресс, XP и звание.
- `src/student-header.js` — колокольчик, уведомления, служебные кнопки шапки.
- `src/course-game.js`, `src/levels.js` — игры, коллекция, прогресс, награды и XP toast.
- `src/periodic.js` — таблица, поиск, случайный элемент, справочные значки.
- `src/welcome-info.js`, `script.js` — иконки welcome; композиция и cursor tracking сохранены.
- `src/auth.js` — служебная иконка показа пароля через Icon.
- `data/welcome.js`, `data/student-interface.js` — удаление декоративных эмодзи из переводов. Старые сохранённые уведомления очищаются только при отображении.
- `data/home-icons.js`, `assets/vendor/LUCIDE-PROVENANCE.json`, `THIRD_PARTY_NOTICES.md` — служебная выборка Lucide и её атрибуция.
- `index.html` — подключение новых файлов, порядок загрузки, версия и ключи кэша.
- `tests/validate_icons.cjs`, `tests/icons_e2e.py` — проверка набора и интеграции на страницах.
- `tests/sidebar_design_e2e.py` — размеры новых плиток вместо старых SVG.
- `tests/intro_e2e.py` — ссылка на следующую тему ищется в основном содержимом, отдельно от одноимённого уведомления.
- `tests/site_package.py`, `tests/release_cache_e2e.py` — выпуск 1.5.0 и публикация в подпапке /fotima/.
- `README.md`, этот файл и `artifacts/icons-*` — описание выпуска, результаты проверки и снимки.
