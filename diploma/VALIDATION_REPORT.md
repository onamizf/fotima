# Протокол проверок

20 октября 2026. Базовая версия приложения для описания: commit `67d2100` (минималистичный интерфейс). Материалы этого этапа не меняют учебный код.

## Метод и пределы

Использованы Python Playwright и Chromium; графическая проверка — настоящий WebGL через программный SwiftShader. Ширины эмулировались, в том числе 375/768/1366 px; отдельные проверки включали 320 px, ландшафт и увеличенный текст. Это не испытания на физических телефонах. Автоматические сценарии выполнялись на разных последовательных версиях проекта: таблица ниже — журнал сохранённых результатов, а не утверждение, что все наборы заново выполнены на последнем commit.

Полный путь через уроки и задания проверен набором progress до упрощения меню. После упрощения отдельно проверены 84 компоновки основных экранов и упаковка сайта. Сценарии всего курса после последней косметической правки полностью повторно не запускались. В этапе 8 проверены корректность ссылок и соответствие чисел сохранённым JSON, без нового запуска всех браузерных наборов.

## Что проверялось функционально

- Прямое открытие лаборатории не заменяет прохождение теории.
- Неправильный порядок и неверное объяснение исправляются; уборка входит в условия готовности.
- Нельзя сменить вариант при активном источнике; отмена не зажигает его повторно.
- Настройки, отдельные образцы и продолжение переживают перезагрузку; повреждённое или недоступное хранилище обрабатывается.
- Награды не появляются раньше условий и не дублируются. Историческая награда отделена от состояния новой попытки.
- Произвольное заполнение справочных полей не даёт полной готовности первой работы.
- Пользовательский текст экранируется в отчётах; скачанный HTML автономен.
- Камера не выполняет учебные действия, а схема остаётся рабочей при потере WebGL. На уровне этих проверок нет запросов к внешнему CDN.

## Повторение технических проверок

Из корня репозитория запустить HTTP-сервер: `python -m http.server 8000`. В другом терминале, где уже установлен Python Playwright и Chromium:

```sh
LAB_TEST_BASE=http://127.0.0.1:8000/ python tests/progress_e2e.py
LAB_TEST_BASE=http://127.0.0.1:8000/ python tests/chemical_e2e.py
LAB_TEST_BASE=http://127.0.0.1:8000/ python tests/lab3d_e2e.py
python tests/site_package.py
```

Это команды для Bash среды разработчика, не команды для обычной Windows cmd. Наборы используют Chromium по пути /usr/bin/chromium и требуют соответствующего окружения; установка браузерных тестов не нужна ученику для пользования сайтом. Тесты могут обновлять снимки и JSON. Изменённый тестовый интерфейс следует согласовать с селекторами проверок; не отключать assertions ради зелёного результата.

## Ручной протокол для заполнения

| Проверка | Устройство, ОС и браузер | Наблюдение | Статус |
| --- | --- | --- | --- |
| Полный путь на компьютере | Указать фактические данные | Пройти DEFENSE_DEMO.md | Не выполнено по этому протоколу |
| Телефон: теория, действия, отчёт | Указать модель и браузер | Касание, прокрутка, читаемость | Не выполнено |
| Планшет и поворот экрана | Указать модель и браузер | Перестройка без потери попытки | Не выполнено |
| 3D и схема на реальном GPU | Указать устройство | Загрузка, контекст, отзывчивость | Не выполнено |
| Проверка преподавателем | Указать роль без личных данных ученика | Термины, образцы, ответы и справки | Ожидается |
| Вычитка четырёх языков | Указать компетенцию проверяющего | Терминология и длинные фразы | Ожидается |

Заказчик сообщил, что рабочая версия видна и интерфейс устраивает. Это пользовательское подтверждение доступности, но не измерение производительности и не завершённая научная приёмка. Независимая проверка GitHub Pages из среды ограничена ответом 403.
