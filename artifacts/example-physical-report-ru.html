Парафин: плавление и охлаждение

Задание пройдено по предварительной модели.

Оборудование

Фарфоровая чашка, парафин, опора и управляемый виртуальный нагреватель.

Выполненные действия

Собрать установку → Поместить парафин в чашку → Включить нагревание → Наблюдать плавление → Выключить нагревание → Начать охлаждение → Наблюдать затвердевание → Убрать рабочее место

Источники выключены, посуда условно остыла и убрана.

Твёрдый парафин стал жидким, затем снова твёрдым.

Изменилось агрегатное состояние; в этой модели нового вещества нет.

Растворение соли и выпаривание

Задание пройдено по предварительной модели.

Оборудование

Стакан, вода, соль, стеклянная палочка, чашка, опора и виртуальный нагреватель.

Выполненные действия

Подготовить стакан воды → Добавить соль → Перемешать → Собрать установку → Перенести раствор в чашку → Включить нагревание → Наблюдать появление кристаллов → Выключить нагревание → Начать охлаждение → Убрать рабочее место

Источники выключены, посуда условно остыла и убрана.

Записанные ответы

Соль растворилась, после удаления части воды появились кристаллы.

Соль оставалась в растворе; удаление воды позволило снова увидеть кристаллы.

Сравнение описаний запахов

Задание пройдено по предварительной модели.

Оборудование

Три подписанные карточки образцов и текстовые справки.

Выполненные действия

Открыть справку: спирт → Открыть справку: уксусная кислота → Открыть справку: эфир → Убрать рабочее место

Источники выключены, посуда условно остыла и убрана.

Записанные ответы

Для двух образцов есть описания, для «эфира» нужно уточнение вещества.

Сравниваются справочные описания физического свойства; нюхать реальные вещества не нужно.

Этиловый спирт: Характерный спиртовой — по справке

Разбавленный раствор уксусной кислоты: Уксусный — по справке

Эфир (название требует уточнения): Описание не назначено: нужно уточнить вещество

Мой вывод

Парафин изменил агрегатное состояние и снова затвердел. При удалении части воды из раствора появились кристаллы соли. В модели новые вещества не образовались. Описания запахов взяты из справки; образец эфира нужно уточнить у преподавателя.

Это текстовая справка, а не запах из браузера. Не нюхай реальные образцы и не пробуй вещества на вкус.

В учебнике указано «эфир». Без уточнения вещества точные свойства и формула не назначаются.

Нет задания на скорость: переходы выполняются кнопками. Количество вещества, пламя и время условные.

Температуры, концентрации и чистота продукта в этой модели не измеряются.

Собственный вывод и сведения об образцах ещё требуют проверки преподавателем. Неопределённый эфир не считается идентифицированным.
