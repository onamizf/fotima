# Версия 1.41.5

## Диагностика

Выбор языка: `src/student-header.js`, четыре значения `ru`, `en`, `uz-Latn`, `uz-Cyrl`. Значение сохраняется в настройках. Тексты распределены между `src/i18n.js`, словарями `data/*` и локализованными данными сцен. В `data/water-bath-i18n.js` все 135 групп раньше содержали русские копии в других языках; часть разделов `equipment-study` тоже не имела переводов. Обычный render повторно монтировал задания и сбрасывал эфемерную сборку.

Добавлен `TaskI18n`: русский fallback с предупреждением, сохранение текущего состояния только для смены языка. Сохранены текущая ситуация, этап и просмотренные шаги, текущий прибор, изученные флаги, режим, частичная сборка, ошибки, подсказки, таймер, глубина, температура, выбранная деталь и undo/redo. Открытая информационная карточка и вид атласа также восстанавливаются. Обычный повторный вход по маршруту по-прежнему начинает попытку сборки с нуля. Тарифы XP и маршруты не менялись.

JSON содержит стабильные i18n-ключи. Полный список новых переводов: [1.41.5-translations.md](1.41.5-translations.md).

## Геометрия

Раньше рамки уже брались из JSON, но assemblyImage/fit игнорировались. Контейнер занимал 75% высоты с ограничением ширины. Теперь общая высота — до 85%, уменьшается только целиком, если не помещается по ширине; низ на уровне стола 91%. Все части используют только assembled, без индивидуальных смещений/масштабов. В разложенном атласе остаются его отдельные анимационные позиции.

| Часть | Изменение assembled |
|---|---|
| boss-clamp | Из обновлённого архива: x 11.39→11.2; w 9.23→9.04; h 6.74→6.42; z 9→10; fit fill |
| clamp-arm | Из архива: x 4.13→4.32; y 21.03→20.06; w 68.17→66.8; h 4.01→5.62; z 9; fit fill |
| wire-gauze | Дополнительно после наложения: y 53.93→55.2, вниз на 1.27% высоты эталона |
| thermometer | Дополнительно: x 61.49→60.73; w 3.93→5.45. Сохранены центр, y и h. Прозрачные поля исходного фото больше не уменьшают видимую высоту через contain |

В evaporation.json координаты не менялись. Обе установки поддерживают assemblyImage и fit. Муфта и лапка точно вырезаны из full.webp. Остальные отдельные рисунки в архиве отличаются по форме от full.webp (ограничение описано README); позиционные рамки проверены, пиксельное совпадение всех рисунков не заявляется. Завершение показывает сам эталон full.webp с переходом 200 мс. Debug-режим накладывает эталон с прозрачностью 35% поверх частей.
