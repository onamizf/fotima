# Версия 1.41.4

Общая шапка сайта подключена к заданиям. На мобильных устройствах высота 56px, дополнительные элементы в меню; полноэкранный режим скрывает шапку. XP обновляется сразу. Боковая навигация открывается по кнопке и не перекрывает сцену постоянно.

В задании 1.1 удалены нижние переключатели A–D, добавлены состояния ситуаций и индикатор фактических этапов: 5 визуальных шагов + 3 карточки разбора. Удалены поиск по заданиям и кнопка «К текущему шагу».

Задание 1.2·1 заменено изучением шести приборов: пробирка, химический стакан, коническая колба, мерный цилиндр, воронка, фарфоровая выпарительная чашка. Все шесть русских описаний предоставлены пользователем; новых описаний не написано. Старые флаги изучения и идентификаторы наград сохранены, повторный просмотр не даёт XP.

Проверки Chromium: 360×800, 768×1024, 1366×768, 1920×1080; шесть демонстраций, клавиатура, касания/свайп, reduced motion, сохранение прогресса, однократные XP, полноэкранный режим, четыре ситуации, обе сборки. Ошибок JavaScript и консоли в проверенных сценариях нет. Safari/WebKit недоступен в среде, проверка в Safari не выполнена.
