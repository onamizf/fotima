# Архив старого входа через Supabase

Эти проверки описывают прежний вход по email и сохранение в Supabase. После перехода на локальные аккаунты по имени они не являются проверками текущего приложения и не запускаются. Код сохранён только как история прежнего контракта; старые пути внутри сценариев не актуализируются.

Текущий контракт проверяют `tests/local_auth_e2e.py`, `tests/routes_theme_e2e.py`, `tests/progress_e2e.py`, `tests/welcome_e2e.py`, `tests/blue_webgl_e2e.py` и `tests/site_package.py`.
