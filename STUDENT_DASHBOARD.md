# Главная ученика — 22 октября 2026

После регистрации или входа по имени открывается `#home`. Гость, открывший `#home`, перенаправляется на `#login`. Прежний каталог остаётся на `#catalog`; экран `#welcome`, его композиция и cursor tracking сохранены.

## Изменения

- `src/dashboard.js` (новый): главная с поиском по действующим данным уроков, веществ, опытов и словаря; клавиатурный выбор результатов; реальные блокировки уровней; продолжение из сохранённого прогресса; рекомендации; закрываемый баннер и уведомления. Отдельные маршруты для таблицы 118 элементов, безопасности, списка тестов, словаря и библиотеки.
- `src/dashboard.css` (новый): светлый рабочий стол поверх синего фона, градиентный hero, карточки, адаптивный ряд разделов, шапка 72px, панель 80/280px во всю высоту и мобильный overlay. Reduced motion отключает анимации.
- `src/profile-menu.js`: профиль с раскрывающимся списком, круглый переключатель языка последним справа; полноэкранная левая панель с подписями, кнопкой начала опыта, уведомлениями и аватаром. На планшетах панель постоянная с 768px, на телефонах — модальная, с закрытием по Escape, снаружи или после перехода.
- `src/app.js`: новая главная и ресурсы, правильный порядок шапки, логотип ведёт на главную текущего пользователя. Панель — сосед шапки в DOM, поэтому не перекрывает логотип; основной контент сдвинут на её ширину.
- `src/auth.js`: успешный вход/регистрация ведут на `#home`; выход доступен только в раскрывающемся меню профиля. Соль, SHA-256, валидация и изоляция прогресса сохранены.
- `src/routes.js`: новые разделы, активная главная для авторизованного ученика, заголовки страниц.
- `index.html`: подключены локальные файлы новой главной; сборщик автоматически включает их в публикацию.
- `tests/dashboard_e2e.py` (новый), существующие проверки входа, маршрутов и упаковки: обновлены под новый путь после входа и меню профиля.

## Данные и ограничения

Баннер не сообщает об открытии физических явлений новому ученику: он отражает реально доступный уровень. Закрытие хранится отдельно для пользователя и уровня в `fotima.banner.<userId>.<topicId>`. Учебные критерии открытия уровней не изменены. Счётчики карточек показывают проверенные шаги (14/4/9), включая теорию, а не выдуманное количество опытов. Таблица элементов содержит символы и порядковые номера; атомные массы не добавлены без источника. Тесты используют существующие вопросы; перед тестом требуется прочитать разделы урока.

Локальные аккаунты и прогресс по-прежнему работают только в данном браузере. Существующие ключи аккаунтов и прогресса не мигрируют и не удаляются.

## Исправление после проверки пользователем — выпуск 0.8.1

Скриншот пользователя показывает старую короткую панель. Новая разметка уже находилась в main; состояние живой публикации из рабочего окружения недоступно (соединение с GitHub Pages и Actions API возвращает 403). Поэтому причина загрузки старого варианта на реальном сайте не считается установленной.

- Убрана отдельная кнопка выхода из боковой панели. Выход остался в меню профиля.
- В базовых `src/shell.css` и `site.css` удалены старые ограничения плавающей карточки: отступы 76/90/96px, высота по содержимому, ширины 78/310px и сдвиг контента 104/334px. Основная и базовая геометрия согласованы: top/left 0, 100dvh, ширина 80/280px.
- `index.html` и `tools/build_site.py`: локальные CSS/JS подключаются с `?v=<SHA-256 содержимого>`. Сборщик вычисляет ключи заново при каждой публикации, поддерживает query-параметры в исходном index и формирует `version.json` с версией, SHA коммита Actions и хешами файлов. Аккаунты и прогресс не очищаются.
- `tests/release_cache_e2e.py`: воспроизводит старый выпуск a604f83 с кэшированием CSS/JS на год, регистрирует ученика, сохраняет запись таблицы, затем открывает актуальную сборку. Проверены новая главная, высота панели ровно 812px при viewport 407×812, отсутствие отдельного выхода и сохранность пользователя/таблицы.
- `tests/site_package.py`: проверяет соответствие версий URL реальному содержимому файлов. Повторно пройдены проверки главной (32 раскладки) и #welcome (24 раскладки).

Примеры актуального вида: `artifacts/sidebar-full-height-407.png`, `artifacts/home-release-407.png`. Для загрузки свежего HTML после публикации: `https://onamizf.github.io/fotima/?v=0.8.1#home`.
