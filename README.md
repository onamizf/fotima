## Локальные аккаунты по имени

Регистрация: имя 3–20 символов, пароль от 8 символов и его повтор. Имя уникально без учёта регистра в этом браузере. Пароль сохраняется только как SHA-256 от индивидуальной случайной соли и пароля через Web Crypto. Сессия и отдельный прогресс пользователя хранятся в localStorage. После входа открывается главная ученика `#home`.

Supabase и вход по email отключены и больше не подключаются к приложению. Прежние записи localStorage и настоящая база не удаляются; они не привязываются автоматически к новым именам. Аккаунты доступны только в данном браузере и на данном адресе сайта; синхронизации между устройствами нет. Локальное хранение не заменяет серверную защиту от пользователя, который может редактировать собственное хранилище браузера. Требуется HTTPS либо localhost для Web Crypto.

## Открыть сайт в Windows

1. Скачать актуальный ZIP из GitHub и распаковать в отдельную папку.
2. Открыть папку с `index.html`, в адресной строке Проводника написать `cmd`, нажать Enter.
3. Выполнить `py -m http.server 8000`. Окно не закрывать.
4. На том же компьютере открыть `http://localhost:8000`. Если ранее был запущен старый сервер, сначала остановить его Ctrl+C, затем запустить из новой папки.

Для Linux: `python -m http.server 8000` из корня проекта. Нужен Python 3; установки зависимостей для сайта нет. В облачной среде нужен предпросмотр/проброс порта, а localhost личного компьютера не ведёт к облачной машине. Заказчик подтвердил доступность публичной рабочей версии; независимая проверка публикации из облачной среды ограничена. Открывать через HTTP, не через file://.

## Что готово

- Настоящая 3D-сцена рабочего места на локальной Three.js: свои модели посуды, материалов и кабинета, освещение/тени, управление обзором и схема при недоступном WebGL. Переключение вида сохраняется.

- Каталог трёх новых работ: физические свойства; физические явления; химические явления.
- Три урока с частями, схемами, словарём и вопросами на четырёх языках (ru, uz-Latn, uz-Cyrl, en), объяснениями ошибок, повтором и сохранением главы/ответов.
- Рабочий стол первой работы: 12 независимых образцов, последовательность действий, текстовые наблюдения, анимация перемешивания, исправление ответов, отмена и сброс. Лабораторная 2: парафин, раствор соли и справочные описания запахов с отдельными состояниями, подсказками и отчётом. Лабораторная 3: четыре примера горения, медь с повторным циклом и кислота с тремя карбонатными образцами — с отдельными действиями, проверкой и отчётом.
- Отчёт первой работы: отдельное сравнение соли и серы после наблюдений, собственный вывод, обзор незаполненных записей, скачивание HTML с печатными стилями.
- Черновик таблицы: 12 образцов, восемь полей свойств на образец, примечание об источнике, сохранение, смена образца, очистка с подтверждением. На телефоне — карточки, на компьютере — таблица.
- Отдельные предварительные справочные карточки качественных свойств. Численные свойства требуют согласования и не выдаются за измерения/проверенные ответы.
- Семь новых статических изображений оборудования для согласования; рисунки собственные.
- Адаптивность, настройки языка, вида и движения, работа при недоступном локальном хранилище с предупреждением. Звуковых эффектов нет.

## Ограничения

Взвешивание и измерение объёма/твёрдости первой работы пока не работают. Горение и химические превращения третьей работы реализованы как управляемые качественные состояния, без свободного смешивания и точной химической динамики. Нагревание, охлаждение и выпаривание управляются как конечные качественные состояния лабораторной 2, без точных температур/концентраций и фонового времени. Проверяются три качественных свойства и объяснение после виртуальных действий; остальная таблица остаётся черновиком. Нет полной автоматической проверки таблицы, полного зачёта первой работы. Достижения выдаются только за описанные цифровые условия, а не за экспертную приёмку или численные свойства. Прохождение трёх цифровых заданий второй работы учитывается отдельно и не заменяет экспертную приёмку. Учебные тексты и качественные справочные карточки предварительные; нужны учебник, источники численных данных и проверка преподавателем/носителями языков. Известны страна и сведения «SHARQ», Ташкент, 2017; авторы будут добавлены позже. Неопределённые образцы спирта, эфира и горючего газа нельзя наделять выдуманными точными свойствами.

Запах представлен описаниями, а не воспроизведением. В приложении нет предложения реально вдыхать пары. Схемы не являются точной физико-химической симуляцией.
