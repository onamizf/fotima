# Лаборатория элементов — химия 7-го класса

**Этап 3: рабочий каркас, ожидает одобрения.** Этапы 0–2 одобрены заказчиком. Готовых уроков и химической механики пока нет. Все страницы помечены как временные демонстрационные данные; завершение демонстрационного маршрута не является оценкой знаний.

## Запуск

Нужен Python 3, установка зависимостей для сайта не требуется.

```bash
cd /workspace/fotima
python -m http.server 8000 --bind 0.0.0.0
```

На компьютере, где запущена команда, открыть `http://localhost:8000`. Если копия проекта расположена в другой папке, сначала перейти в неё. Для телефона в одной локальной сети использовать адрес компьютера и порт 8000. На облачной машине нужен встроенный просмотр порта 8000 или проброс порта; localhost на личном компьютере сам по себе не ведёт к облачной машине. Публичного развёртывания нет, внутренние пути /workspace не являются интернет-ссылками.

Открывать через HTTP-сервер: поведение localStorage при открытии index.html как локального файла браузер не гарантирует. Статические файлы не требуют сборки и размещения API. Шрифт и графика поставляются локально; после получения файлов сервер не загружает сторонние ресурсы.

## Что работает

- Главная → каталог → теория выбранной темы → лаборатория → демонстрационный результат; навигация назад/вперёд браузера, прямые адреса и перезагрузка.
- Все три карточки сохраняют свою тему, а не ведут в один и тот же урок.
- Адаптивные стили утверждённого дизайна, локальный Inter и собственная SVG-посуда.
- Четыре языка: ru, uz-Latn, uz-Cyrl, en; переводятся навигация, настройки, статусы, временные тексты и доступные имена. Язык документа обновляется, выбор предмета при переключении языка сохраняется.
- Настройки языка, звука и уменьшения движения; включение звука пока только настройка, звуковых эффектов нет.
- Сохранение демонстрационного прогресса отдельно по каждой теме и выбранного демонстрационного предмета; состояние после перезагрузки восстанавливается. Это выбранное решение для незавершённой попытки на этапе 3. Полноценная модель попыток будет добавлена позже.
- Сброс только данных этого приложения с подтверждением; отмена сброса ничего не меняет. При повторе ранее завершённая отметка не снимается.
- Обработка повреждённых данных и недоступного localStorage: сайт остаётся доступен, при невозможности сохранения показано предупреждение. Аккаунтов и личных данных учеников нет.

Структура: `src/i18n.js` — словари утверждённого прототипа; `src/content.js` — временные тексты каркаса и темы; `src/storage.js` — проверка и сохранение данных; `src/illustrations.js` — рисунки макетов; `src/app.js` — страницы и навигация; `src/styles.css` — стили. `design/` сохраняет согласованный прототип этапа 2. Лицензия Inter: `assets/OFL.txt` (SIL OFL 1.1). Внешних JS-библиотек в сайте нет.

## Как проверить вручную

1. Открыть каталог. Все темы в чистом браузере не начаты. Выбрать любую тему: заголовок соответствует карточке, появляется статус «В процессе».
2. Перейти из временной теории в лабораторию. Выбрать предмет, изменить язык, перезагрузить: выбор и язык сохранены.
3. Нажать «Завершить демонстрационный маршрут». На результате ясно написано, что это демонстрация. В каталоге отмечена только эта тема. Перезагрузить: отметка сохраняется.
4. В настройках включить уменьшение движения и звук, перезагрузить. Затем проверить отмену и подтверждение сброса. Подтверждённый сброс возвращает русский язык и исходные настройки, очищает демонстрационные отметки и выбранные предметы.
5. Открыть страницы при узком окне и с клавиатуры: навигация и выбор доступны без перетаскивания.

## Автоматическая проверка

В текущей среде есть Python Playwright и системный `/usr/bin/chromium`. При работающем сервере на порту 8000:

```bash
python tests/smoke.py
```

На другом компьютере это необязательные зависимости только для проверки, не для запуска сайта; при необходимости установить Python-пакет playwright и указать путь к локальному Chromium в smoke.py.

Результат: `artifacts/stage3-validation.json`. Проверено 96 сочетаний (6 страниц × 4 языка × 4 ширины: 320/375/768/1366 CSS px), без горизонтального переполнения страницы. Отдельно проверены три маршрута, смена языка, перезагрузка настроек/выбора/демонстрационного завершения, история браузера, подтверждение сброса, защита от зачёта прямым открытием результата, повреждённое и недоступное хранилище. Ошибок JavaScript не обнаружено.

Это эмуляция Chromium, а не испытание на реальных телефонах, Safari или Firefox. Снимки текущего сайта — `artifacts/stage3-375.png`, `stage3-768.png`, `stage3-1366.png`.

## Ограничения и граница этапа

- Нет законченных уроков, вопросов с оцениванием, фильтрации, растворения, дозирования и достижений. Демонстрационный выбор предмета не является лабораторной механикой.
- Используется отдельный ключ localStorage `fotima.chemistry7.shell.v1`, только с демонстрационными данными. Эти отметки нельзя автоматически выдавать за настоящий учебный прогресс будущей версии.
- Нет облачной синхронизации; браузер/устройство и адрес сайта имеют собственные данные. Очистка данных браузера удаляет местный прогресс.
- Переводы требуют вычитки; содержимое ещё должен проверить преподаватель по учебнику.
- Полный аудит WCAG, реальные устройства и полноценные ученические опыты относятся к дальнейшим этапам.

Этап 4 не начат. Следующий этап — только после явного одобрения заказчика.
