# Виртуальная лаборатория химии · 7 класс · Узбекистан

**Текущая работа:** минималистичная игровая оболочка с оригинальной лягушкой-химиком, короткими карточками и компактным входом. [Описание и проверки](MINIMAL_FROG_DESIGN.md). Три последовательных уровня сохранены; [их правила](GAME_LEVELS.md) не изменены.

## Аккаунты Supabase — включены, ожидается проверка реального входа

Подготовлены регистрация, вход, восстановление пароля и сохранение между устройствами. После подтверждения владельцем создания таблицы и настройки адресов вход **включён**. При открытии сайта сначала отображается регистрация; после входа — главная лаборатории. Инструкция владельцу: [supabase/README.md](supabase/README.md). Проверки клиента выполнены на тестовом API; реальный проект и RLS ещё требуют проверки.

## Открыть сайт в Windows

1. Скачать актуальный ZIP из GitHub и распаковать в отдельную папку.
2. Открыть папку с `index.html`, в адресной строке Проводника написать `cmd`, нажать Enter.
3. Выполнить `py -m http.server 8000`. Окно не закрывать.
4. На том же компьютере открыть `http://localhost:8000`. Если ранее был запущен старый сервер, сначала остановить его Ctrl+C, затем запустить из новой папки.

Для Linux: `python -m http.server 8000` из корня проекта. Нужен Python 3; установки зависимостей для сайта нет. В облачной среде нужен предпросмотр/проброс порта, а localhost личного компьютера не ведёт к облачной машине. Заказчик подтвердил доступность публичной рабочей версии; независимая проверка публикации из облачной среды ограничена. Открывать через HTTP, не через file://.

## Что готово

- Настоящая 3D-сцена рабочего места на локальной Three.js: свои модели посуды, материалов и кабинета, освещение/тени, управление обзором и схема при недоступном WebGL. Переключение вида сохраняется.
- «Мой прогресс»: отдельные показатели и статусы, пять наград с условиями и историей, продолжение с выбранного образца, общий список восьми химических вариантов.
- Каталог трёх новых работ: физические свойства; физические явления; химические явления.
- Три урока с частями, схемами, словарём и вопросами на четырёх языках (ru, uz-Latn, uz-Cyrl, en), объяснениями ошибок, повтором и сохранением главы/ответов.
- Рабочий стол первой работы: 12 независимых образцов, последовательность действий, текстовые наблюдения, анимация перемешивания, исправление ответов, отмена и сброс. Лабораторная 2: парафин, раствор соли и справочные описания запахов с отдельными состояниями, подсказками и отчётом. Лабораторная 3: четыре примера горения, медь с повторным циклом и кислота с тремя карбонатными образцами — с отдельными действиями, проверкой и отчётом.
- Отчёт первой работы: отдельное сравнение соли и серы после наблюдений, собственный вывод, обзор незаполненных записей, скачивание HTML с печатными стилями.
- Черновик таблицы: 12 образцов, восемь полей свойств на образец, примечание об источнике, сохранение, смена образца, очистка с подтверждением. На телефоне — карточки, на компьютере — таблица.
- Отдельные предварительные справочные карточки качественных свойств. Численные свойства требуют согласования и не выдаются за измерения/проверенные ответы.
- Семь новых статических изображений оборудования для согласования; рисунки собственные.
- Адаптивность, настройки языка, вида и движения, работа при недоступном локальном хранилище с предупреждением. Звуковых эффектов нет.

Описание текущей поставки: [CURRICULUM_UPDATE.md](CURRICULUM_UPDATE.md). Согласованные сценарии: [REVISED_LABORATORY_SCENARIOS.md](REVISED_LABORATORY_SCENARIOS.md). Тексты для преподавателя: [LESSON_CONTENT_REVIEW.md](LESSON_CONTENT_REVIEW.md).

## Ограничения

Взвешивание и измерение объёма/твёрдости первой работы пока не работают. Горение и химические превращения третьей работы реализованы как управляемые качественные состояния, без свободного смешивания и точной химической динамики. Нагревание, охлаждение и выпаривание управляются как конечные качественные состояния лабораторной 2, без точных температур/концентраций и фонового времени. Проверяются три качественных свойства и объяснение после виртуальных действий; остальная таблица остаётся черновиком. Нет полной автоматической проверки таблицы, полного зачёта первой работы. Достижения выдаются только за описанные цифровые условия, а не за экспертную приёмку или численные свойства. Прохождение трёх цифровых заданий второй работы учитывается отдельно и не заменяет экспертную приёмку. Учебные тексты и качественные справочные карточки предварительные; нужны учебник, источники численных данных и проверка преподавателем/носителями языков. Известны страна и сведения «SHARQ», Ташкент, 2017; авторы будут добавлены позже. Неопределённые образцы спирта, эфира и горючего газа нельзя наделять выдуманными точными свойствами.

Запах представлен описаниями, а не воспроизведением. В приложении нет предложения реально вдыхать пары. Схемы не являются точной физико-химической симуляцией.

## Структура и проверка

`src/curriculum/` — новые подписи, таблица и образцы предметов; `src/lessons/` — четыре независимых набора учебных текстов; `src/lesson-view.js` и `lesson-state.js` — уроки и проверка понимания; `src/app.js` — страницы; `src/storage.js` — данные. Старый `src/lab/` остаётся в истории проекта и не подключён в index.html.

Сайт статический, без сборки. Three.js 0.160.1 включена локально (MIT), CDN не требуется; сведения — [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). Модели и процедурные текстуры свои. Inter загружается локально, лицензия SIL OFL 1.1 сохранена в assets/OFL.txt. Дизайн и ранние отчёты оставлены как исторические артефакты.

Текущие проверки из корня проекта:

```bash
node tests/validate_lessons.cjs
python -m http.server 8010
```

В другом терминале:

```bash
python tests/curriculum_e2e.py
python tests/investigation_e2e.py
python tests/property_report_e2e.py
python tests/physical_e2e.py
python tests/physical_long_text.py
python tests/chemical_e2e.py
python tests/lab3d_e2e.py
python tests/specimens3d_e2e.py
python tests/progress_e2e.py
```

Для браузерного теста используются установленные в среде Python Playwright и `/usr/bin/chromium`. Они не требуются для обычного запуска. Адрес тестового сервера можно изменить переменной LAB_TEST_BASE. Проверяются все темы/языки, неверные и правильные ответы, таблица/карточки, сохранение, перенос только настроек, сброс, некорректные данные и экранирование ввода. Отчёт: artifacts/curriculum-validation.json, снимки: artifacts/curriculum-*.png.

Массовые функциональные проверки используют схематичный путь без WebGL; отдельный tests/lab3d_e2e.py запускает настоящий WebGL через SwiftShader и проверяет связь моделей с действиями, обзор и потерю контекста. Проверки — эмуляция Chromium, не испытание реальных телефонов, Safari или Firefox. Прежние smoke.py, lessons_e2e.py и lab_e2e.py относятся к историческому составу этапов 3–5; для его воспроизведения используется соответствующий Git-коммит. Они не являются текущими приёмочными тестами нового состава.

После показа текущей механики ждём явного одобрения перед реализацией следующих опытов.

## Доимий онлайн ҳавола / GitHub Pages

Пользователь разрешил публикацию текущей версии. Автоматическое обновление сайта настроено через `.github/workflows/pages.yml`; для первого запуска нужно один раз выбрать GitHub Actions в Settings → Pages. Пошаговая инструкция на узбекском: [ONLINE_SETUP.md](ONLINE_SETUP.md).

Ожидаемый адрес после успешной активации: `https://onamizf.github.io/fotima/`. По снимку заказчика запуск GitHub Actions находится в очереди; по его просьбе дальнейшая настройка отложена. Публикация ещё не подтверждена: API GitHub и Pages-домен недоступны из текущей среды (403). Настроенный workflow и прошедшая локальная проверка пакета не означают, что сайт уже доступен онлайн.

Для упаковки: `python tools/build_site.py --output _site` в пустой выходной каталог. Для проверки публикационного пакета: `python tests/site_package.py`. В пакет входят только файлы, нужные браузеру; документация и ответы для преподавателя исключены.
