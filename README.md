# Виртуальная лаборатория химии · 7 класс · Узбекистан

**Текущий этап:** этап 5 после пересмотра состава. Работает качественное исследование 12 образцов: осмотр, проба с водой, справка о запахе, проверка трёх свойств и объяснения. Полный зачёт лабораторной и численные измерения пока недоступны. Добавлены сравнение, собственный вывод и скачиваемый автономный отчёт. Текущая поставка ожидает одобрения: [PROPERTY_REPORT.md](PROPERTY_REPORT.md). Механика наблюдений описана в [INVESTIGATION_STAGE5.md](INVESTIGATION_STAGE5.md).

## Открыть сайт в Windows

1. Скачать актуальный ZIP из GitHub и распаковать в отдельную папку.
2. Открыть папку с `index.html`, в адресной строке Проводника написать `cmd`, нажать Enter.
3. Выполнить `py -m http.server 8000`. Окно не закрывать.
4. На том же компьютере открыть `http://localhost:8000`. Если ранее был запущен старый сервер, сначала остановить его Ctrl+C, затем запустить из новой папки.

Для Linux: `python -m http.server 8000` из корня проекта. Нужен Python 3; установки зависимостей для сайта нет. В облачной среде нужен предпросмотр/проброс порта, а localhost личного компьютера не ведёт к облачной машине. Доступность публичного сайта пока не подтверждена. Открывать через HTTP, не через file://.

## Что готово

- Каталог трёх новых работ: физические свойства; физические явления; химические явления.
- Три урока с частями, схемами, словарём и вопросами на четырёх языках (ru, uz-Latn, uz-Cyrl, en), объяснениями ошибок, повтором и сохранением главы/ответов.
- Рабочий стол первой работы: 12 независимых образцов, последовательность действий, текстовые наблюдения, анимация перемешивания, исправление ответов, отмена и сброс. Лабораторные 2–3 пока содержат теорию и описание заданий.
- Отчёт первой работы: отдельное сравнение соли и серы после наблюдений, собственный вывод, обзор незаполненных записей, скачивание HTML с печатными стилями.
- Черновик таблицы: 12 образцов, восемь полей свойств на образец, примечание об источнике, сохранение, смена образца, очистка с подтверждением. На телефоне — карточки, на компьютере — таблица.
- Отдельные предварительные справочные карточки качественных свойств. Численные свойства требуют согласования и не выдаются за измерения/проверенные ответы.
- Семь новых статических изображений оборудования для согласования; рисунки собственные.
- Адаптивность, настройки языка/звука/движения, работа при недоступном локальном хранилище с предупреждением. Звуковых эффектов нет.

Описание текущей поставки: [CURRICULUM_UPDATE.md](CURRICULUM_UPDATE.md). Согласованные сценарии: [REVISED_LABORATORY_SCENARIOS.md](REVISED_LABORATORY_SCENARIOS.md). Тексты для преподавателя: [LESSON_CONTENT_REVIEW.md](LESSON_CONTENT_REVIEW.md).

## Ограничения

Взвешивание, измерение объёма и твёрдости, нагревание, выпаривание, горение и реакции пока не работают. Проверяются три качественных свойства и объяснение после виртуальных действий; остальная таблица остаётся черновиком. Нет полной автоматической проверки таблицы, зачёта новых практических работ и достижений. Учебные тексты и качественные справочные карточки предварительные; нужны учебник, источники численных данных и проверка преподавателем/носителями языков. Известны страна и сведения «SHARQ», Ташкент, 2017; авторы будут добавлены позже. Неопределённые образцы спирта, эфира и горючего газа нельзя наделять выдуманными точными свойствами.

Запах представлен описаниями, а не воспроизведением. В приложении нет предложения реально вдыхать пары. Схемы не являются точной физико-химической симуляцией.

## Структура и проверка

`src/curriculum/` — новые подписи, таблица и образцы предметов; `src/lessons/` — четыре независимых набора учебных текстов; `src/lesson-view.js` и `lesson-state.js` — уроки и проверка понимания; `src/app.js` — страницы; `src/storage.js` — данные. Старый `src/lab/` остаётся в истории проекта и не подключён в index.html.

Сайт статический, без сборки и внешних JS-библиотек. Inter загружается локально, лицензия SIL OFL 1.1 сохранена в assets/OFL.txt. Дизайн и ранние отчёты оставлены как исторические артефакты.

Текущие проверки из корня проекта:

```bash
node tests/validate_lessons.cjs
python -m http.server 8010
```

В другом терминале:

```bash
python tests/curriculum_e2e.py
python tests/investigation_e2e.py
python tests/property_report_e2e.py
```

Для браузерного теста используются установленные в среде Python Playwright и `/usr/bin/chromium`. Они не требуются для обычного запуска. Адрес тестового сервера можно изменить переменной LAB_TEST_BASE. Проверяются все темы/языки, неверные и правильные ответы, таблица/карточки, сохранение, перенос только настроек, сброс, некорректные данные и экранирование ввода. Отчёт: artifacts/curriculum-validation.json, снимки: artifacts/curriculum-*.png.

Проверки — эмуляция Chromium, не испытание реальных телефонов, Safari или Firefox. Прежние smoke.py, lessons_e2e.py и lab_e2e.py относятся к историческому составу этапов 3–5; для его воспроизведения используется соответствующий Git-коммит. Они не являются текущими приёмочными тестами нового состава.

После показа текущей механики ждём явного одобрения перед реализацией следующих опытов.

## Доимий онлайн ҳавола / GitHub Pages

Пользователь разрешил публикацию текущей версии. Автоматическое обновление сайта настроено через `.github/workflows/pages.yml`; для первого запуска нужно один раз выбрать GitHub Actions в Settings → Pages. Пошаговая инструкция на узбекском: [ONLINE_SETUP.md](ONLINE_SETUP.md).

Ожидаемый адрес после успешной активации: `https://onamizf.github.io/fotima/`. По снимку заказчика запуск GitHub Actions находится в очереди; по его просьбе дальнейшая настройка отложена. Публикация ещё не подтверждена: API GitHub и Pages-домен недоступны из текущей среды (403). Настроенный workflow и прошедшая локальная проверка пакета не означают, что сайт уже доступен онлайн.

Для упаковки: `python tools/build_site.py --output _site` в пустой выходной каталог. Для проверки публикационного пакета: `python tests/site_package.py`. В пакет входят только файлы, нужные браузеру; документация и ответы для преподавателя исключены.
